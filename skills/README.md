# Agora Skills

Skills are portable Markdown procedures that help a researcher or agent perform recurring tasks consistently. They are not autonomous agents, validated expertise, legal authority, or evidence by themselves. They should work across LLMs and human researchers; use explicit inputs, outputs, checks, and escalation points.

## Skill format

Each skill declares `name`, `purpose`, `inputs`, `procedure`, `quality checks`, `failure modes`, and `output`. Keep claims tied to sources; link to the root research protocol. Skills are draft until reviewed and tested on real examples. Do not silently change the research standard through an individual skill.

## Initial skills

- [`comparative-governance`](comparative-governance/SKILL.md): compare institutional forms without flattening context.
- [`ai-governance-review`](ai-governance-review/SKILL.md): map actors, authority, obligations, controls, and remedies in an AI governance proposal.
- [`delegation-design`](delegation-design/SKILL.md): specify and test bounded human–AI delegation and handoffs.

## Future skills

Potential additions include historical case synthesis, source appraisal, participatory design review, governance evaluation, flourishing measurement, and publication preparation. Add only when a repeated workflow and checkable quality criteria are clear.
