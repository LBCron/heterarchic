# Watchlist

Named sources the intake sweep monitors. One line each on *why*, because an unexplained watchlist becomes an RSS feed nobody reads.

**Rules:** a source enters only with a reason and a URL. A source is removed if it produced nothing actionable in four cycles, or if it stops publishing. Adding a source does not imply endorsement — see `INTAKE.md` non-goals.

**Last verified:** 2026-11-06 (links checked with HTTP HEAD)

## Not watched, deliberately

- General AI news outlets: high volume, low evidence grade, and the sweep would fill with announcements.
- Vendor blogs: grade C by construction. If a vendor claim matters, it arrives as a candidate with a named source instead.
- Social media: a lead source at best; leads need a named source before they enter a record.
